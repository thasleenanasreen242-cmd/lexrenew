# LexRenew MVP

LegalTech SaaS for tracking contracts, licences, insurance, leases, AMCs, certificates and compliance renewals.

## Current MVP
- Responsive dashboard
- Search and category filtering
- Add-obligation modal
- Browser localStorage persistence
- Renewal risk indicators
- Intelligence/priority panel
- SEO-ready Next.js App Router foundation

## Next production layer
1. Supabase Auth + organizations
2. PostgreSQL obligations table + RLS
3. Document storage
4. Email reminder scheduler
5. Calendar view
6. Team roles and audit log
7. Stripe billing
8. AI extraction from uploaded contracts
